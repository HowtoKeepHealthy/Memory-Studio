# Memory Studio

Windows x64 进程内存工作台，C++20 扫描核心 + C# / .NET 10 WPF 界面。中文深色界面，青绿色强调色，结果分页和后台扫描。

## 直接运行

双击根目录的 **run.cmd**，或运行 **artifacts/release/MemoryStudio.exe**。发布目录已包含 .NET 桌面运行时，使用成品无需另外安装 .NET。复制成品时请复制整个 artifacts/release 文件夹。

1. 选择进程，点击“连接”；也可以点击“启动演示”，自动连接随附的 DemoTarget。
2. 选择数据类型、搜索条件和值，点击“首次扫描”。再次扫描支持精确值、变化、未变化、增加和减少。
3. 双击结果加入地址表，选中监视项后写入新值；勾选锁定每 500 ms 恢复监视值。取消勾选即可停止锁定。
4. 选中结果点击“查看内存”，可浏览地址附近的十六进制字节与文本。
5. 地址表可保存为 .mstable 文件并在连接进程后加载；加载默认不启用锁定。

演示进程初始生命值 **100**（4 字节整数）、金币 **2500**、速度 **1.25**（单精度）。演示窗口按 H 减少生命，G 增加金币，S 增加速度，R 重置，P 打印，Q 退出。

## 功能与边界

- 支持 1/2/4/8 字节整数、单/双精度浮点、UTF-8、UTF-16 和精确字节序列。
- 数值支持未知初始值；字符串/字节支持精确、变化和未变化筛选，再次扫描保持原来的类型和长度。
- 可限定十六进制地址范围（结束地址不包含在范围内）、自然对齐、仅扫描可写区域。地址留空表示默认范围。
- 候选地址上限为 2,000,000；超过上限或取消会保留上次成功的结果。未知初始值扫描大进程时，应先缩小地址范围。
- 结果每页 200 条，候选地址与比较快照留在 C++ 核心。监视项每 500 ms 更新，扫描期间暂停监视更新和冻结写入。
- 地址表当前保存绝对地址，进程重启后地址可能变化。尚未实现指针扫描、断点调试、汇编脚本及 CE .CT 兼容。
- 普通进程可以直接访问；访问失败会显示具体错误。运行权限需要与目标进程相匹配。

## 开发环境

项目内已配置 **.NET SDK 10.0.401** 和 **llvm-mingw 20260922 / Clang C++20**，不会依赖本机旧 MinGW。编译器下载校验 SHA-256。

- 双击 **build.cmd**：构建 C++ 核心、演示进程、测试程序并发布完整 WPF 应用。
- 运行 **build.cmd -Test**：构建后执行 native 和 managed/界面工作流集成测试。
- 双击 **dev.cmd**：打开已配置 dotnet 和 clang++ 路径的项目终端。
- IDE 可打开 **MemoryStudio.slnx**。核心 C ABI 定义位于 native/memory_core.h。

工具链缺失时构建脚本会下载项目内的固定版本工具。产物位于 artifacts/release，测试报告位于 artifacts/managed-test.txt。构建原生核心也可单独运行 scripts/build-native.ps1。

## 结构

| 目录 | 内容 |
| --- | --- |
| app | WPF 界面、MVVM、C ABI 调用和监视服务 |
| native | Win32 进程访问、内存扫描、快照筛选、C ABI |
| tests | 真实页内存集成测试与演示目标 |
| scripts | 便携工具链安装和构建脚本 |
| artifacts | 编译产物、运行成品、验证报告及界面预览 |
| .tools | 项目内 SDK 和编译器 |

扫描失败和取消采用事务性提交；C ABI 不跨边界抛异常。UI 与核心通过批量分页传输地址，扫描和内存查看在后台执行。
